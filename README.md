# 📱 УПК: Цифровой помощник колледжа

Веб-система для регистрации и обработки обращений о неисправностях в колледже. Разработано для хакатона.

## 🛠 Стек технологий
- **Backend:** Python, Flask, SQLite
- **Frontend:** HTML, CSS, Vanilla JS
- **ИИ-модуль:** Локальная классификация (демо-режим)

## 🚀 Как запустить локально
1. Установите Python 3.10+.
2. Склонируйте репозиторий.
3. Создайте виртуальное окружение: `python -m venv venv`
4. Активируйте его: `venv\Scripts\activate` (Windows) или `source venv/bin/activate` (Mac/Linux).
5. Установите зависимости: `pip install -r requirements.txt`
6. Запустите сервер: `python app.py`
7. Откройте в браузере: `http://localhost:8000`
